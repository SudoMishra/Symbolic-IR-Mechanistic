Stage 00 · infrastructure

Can the paired experiment be trusted?

Before measuring representation effects, a 20-record smoke test validates canonical example construction, paired rendering, inference, parsing, and append-only artifact capture.

completevalidationpaired design

Gate in one line. The full path from one semantic example to matched identifier conditions and recorded outputs completed successfully.

Decisionproceed
01 · question

Does paired rendering change only the identifier surface?

Every later comparison depends on canonical semantic units being held fixed while identifier form changes. A successful model call is not enough: the run must preserve pairing, parse outputs, and retain provenance.

Hypothesis

A single canonical record can render into parallel identifier families with identical question, facts, distractors, answer, and source ordering.

Falsifier

Any mismatch in semantic content, lost pairing keys, unrecoverable output, or non-reproducible artifact path blocks the behavioral program.

02 · design

A deliberately small end-to-end run

Construct

Generate canonical questions, evidence passages, gold answers, and gold source keys.

Render

Produce matched prompt variants without independently authoring their text.

Record

Capture config, model output, parsing fields, metrics, and run identity in raw JSONL.

Invariant

Identifier form is a presentation-layer treatment. The underlying semantic record remains the same object across arms.

The harness is suitable for larger paired comparisons. This result validates measurement plumbing; it says nothing about whether one identifier representation is better.

04 · interpretation

Infrastructure evidence, not model evidence

The smoke test establishes that later deltas can be attributed to defined prompt treatments rather than separately sampled examples. It also makes raw outputs inspectable when a metric looks surprising.

05 · boundaries

What Stage 00 does not establish

No accuracy claim

Twenty records are not used to estimate a model effect.

No runtime generalization

Passing one environment does not guarantee every model, tokenizer, or GPU configuration.

Quality rule

Later anomalous results still require raw-output inspection. A passed harness does not make parsers infallible.
