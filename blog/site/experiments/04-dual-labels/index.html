Stage 04 · ablation

Does an alias beside the UUID fix the problem?

A four-arm MuSiQue ablation compares alias-only, UUID-only, dual labels, and UUIDs with no citation requirement on identical evidence.

completebehavioralablation

Result in one line. Dual labels did not reliably recover alias-only performance; removing literal UUID reproduction restored answer capacity in some model cells.

Cohort100 MuSiQue questions
Context20 passages

Rolemechanism control
01 · question

Can we keep backend IDs visible and add a friendly alias?

A common migration shortcut emits both values, for example Source 8ce71… [S1]. It preserves direct traceability but may retain the input burden and add a second binding target.

Hypothesis

If compact aliases are sufficient, dual labels should approach alias-only binding and answer quality.

Falsifier

If dual labels remain close to UUID-only behavior, merely appending an alias is not a clean substitute for canonicalization.

02 · design

Four views of the same multi-hop evidence

Alias only

Source [S1]; compact reference in context and output.

UUID only

Raw identifier is read and reproduced.

Dual label

UUID and alias both appear; the response cites the alias.

No reproduction

UUID remains in context but the response has no citation obligation.

Isolation goal

The no-reproduction arm separates the burden of reading UUID-bearing context from the obligation to emit the literal string.

03 · results

Supports

UUID-bearing input and UUID reproduction are separable burdens. Keeping the raw value in context while adding an alias does not consistently remove the first burden.

04 · interpretation

Canonicalize instead of annotating

The cleaner interface is one symbolic identifier in model space and one reversible mapping in trusted software. Dual labels preserve the exact coupling the alias was supposed to remove.

Causal caution

The no-reproduction control also changes output instructions. Its improvement does not isolate literal emission from instruction complexity or their interaction.

05 · boundaries

Cell-level and task-specific evidence

Not universal

Recovery differs across models; ceiling cells leave little room to improve.

One cohort

The ablation reuses the 100-question MuSiQue cohort at 20 sources rather than an independent scaled replication.
